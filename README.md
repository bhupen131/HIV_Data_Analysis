<h2>🧹 HIV Data Analysis</h2>

<h3>📌 Project Summary</h3>
<p>
For this HIV data analysis task, I worked with three <b>WHO datasets</b> containing data from <b>1990 to 2019</b>. Before visualizing the data in Tableau, it was essential to clean and prepare the datasets. I used <b>Python</b> for the data cleaning process — first cleaning each dataset individually, and then merging all three using an inner join. The final cleaned and merged dataset was exported to an <b>Excel file</b>, which was later used for creating visualizations in <b>Tableau</b>.
</p>

<h3>🧹 Data Cleaning and Preparation</h3>
<ul>
  <li>Cleaned and prepared three separate WHO datasets using <b>Python</b>, ensuring consistency and quality for analysis.</li>
  <li>Merged all datasets into one consolidated file after individual preprocessing.</li>
  <li>Exported the final dataset to <b>Excel</b> for further analysis and visualization.</li>
</ul>

<h3>📊 Data Visualization</h3>
<ul>
  <li>Visualized the cleaned data in <b><a href="https://public.tableau.com/views/HIV-DataAnalysis/Dashboard1?:language=en-US&:sid=&:redirect=auth&:display_count=n&:origin=viz_share_link" target="_blank">Tableau</a></b> to uncover long-term trends and insights related to HIV prevalence across countries and years.</li>
  <li>Delivered interactive dashboards to highlight key findings and support data-driven understanding of global HIV patterns.</li>
</ul>


<h3>💡 Key Objectives</h3>
<ul>
  <li>Ensure the data is cleaned and merged accurately for analysis.</li>
  <li>Perform visual analysis of HIV prevalence trends across different regions.</li>
  <li>Provide insights through interactive Tableau dashboards.</li>
</ul>
